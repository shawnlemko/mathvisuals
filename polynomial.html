x-intercepts

Same number, three names:

x-intercept: on the graph

A point where the graph crosses or touches the x-axis. Its y-value is always 0.

Example: the graph hits the x-axis at (2, 0).

zero: of the function

An x-value you put in that makes the function come out to 0.

Example: P(2) = 0, so 2 is a zero of P(x).

root: of the equation

A solution you get when you solve the equation P(x) = 0.

Example: solving P(x) = 0 gives x = 2, so x = 2 is a root.

The graph has x-intercepts, the function has zeros, the equation has roots. They all use the same number.
