Why −4.9?

Physics 20 gives the distance an object moves when it speeds up at a steady rate:

d = v₁t + ½at²

For a falling object the acceleration is gravity: a = g = −9.81 m/s². It is negative because gravity pulls down.

Then height = starting height + distance moved, so h = −4.9t² + v₀t + h₀. Here v₀ is the same as v₁: the starting (initial) velocity.

On the Moon, g = −1.62 m/s², so the t² number is −0.81.
